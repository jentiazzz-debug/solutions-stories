# Solutions Stories

Бот режет картинку на стенку из сторис для профиля Telegram и делает
рамки для аватарок. Оплата — звёздами, без платёжного провайдера.

Бот: [@SolutionsStoriesbot](https://t.me/SolutionsStoriesbot) ·
соседний проект: [@emojimakerobot](https://t.me/emojimakerobot)

## Как это устроено

Сетка профиля Telegram выкладывает истории в три колонки: свежая —
слева сверху, старая — справа снизу. В превью от кадра 9:16 видно не
всё, а центральное окно 4:5. Значит, чтобы куски сошлись в полотно,
стыковать надо именно эти окна:

```
┌──────────┐   1080×1920 — сам кадр сторис
│   поля   │
├──────────┤   ← 285 px
│1080×1350 │   ← это окно видно в сетке профиля
├──────────┤
│   поля   │
└──────────┘
```

Отсюда всё остальное:

* частей всегда кратно трём — колонок в сетке ровно три;
* идеальная пропорция исходника считается, а не подбирается на глаз:
  `(3·4) : (rows·5)` — 6:5 для шести частей, 4:5 для девяти, 3:5 для
  двенадцати, 12:25 для пятнадцати;
* файлы отдаются **в порядке публикации**: первый — правый нижний угол,
  последний — левый верхний;
* поля вокруг окна заливаются размытым продолжением кадра (`FILL_MODE`),
  чтобы открытая целиком история не выглядела обрезком.

Рамки для аватарок рисуются кодом, а не лежат картинками: параметрический
венок масштабируется под любой размер и не тащит за собой папку PNG.
Настоящие рамки можно положить в `assets/frames/*.png` — они подхватятся
поверх процедурных.

## Запуск

```bash
cp .env.example .env     # вписать BOT_TOKEN и ADMIN_IDS
pip install -r requirements.txt
python main.py
```

На Windows — `run.bat`: сам создаст venv и поставит зависимости.

Проверить картиночную часть без Telegram:

```bash
python selfcheck.py              # на синтетической шахматке
python selfcheck.py фото.jpg     # на своём фото
```

Результат — в `_selfcheck/`.

## Настройки

Всё в `.env`, см. `.env.example`.

| Переменная | Что делает |
|---|---|
| `BOT_TOKEN` | токен от @BotFather |
| `ADMIN_IDS` | кому открыта `/admin` |
| `PRICES` | `частей:звёзды`, через запятую |
| `FRAME_PRICE` | цена рамки для аватарки |
| `REF_PER_FREE` | сколько активных рефералов = 1 бесплатная генерация |
| `WELCOME_CREDITS` | бесплатных генераций новичку |
| `FILL_MODE` | `blur` или `black` — поля вокруг окна |
| `DATA_DIR` | том под базу, если хостинг даёт отдельный |

## Оформление

Картинки-заставки кладутся в `assets/` и подхватываются по имени. Можно
нарисовать их где угодно — бот просто берёт файл:

| Файл | Где показывается |
|---|---|
| `welcome.jpg` | сразу после `/start` |
| `about.jpg` | кнопка «💡 Для чего это» |
| `manual.jpg` | кнопка «📘 Инструкция» |
| `frames.jpg` | кнопка «🖼 Рамки для авы» |

Размер — **1080×1350** (4:5, вертикаль). Telegram сжимает фото до 1280 по
длинной стороне, так что больше смысла не имеет, а меньше — мылит.
Файлов нет — бот отправит те же тексты без картинки и не упадёт.

`make_assets.py` пересобирает эти четыре файла кодом. Если рисуешь их
сам, скрипт можно просто не запускать: он только перезапишет `assets/`.

### Свои рамки

Любой PNG с прозрачностью из `assets/frames/` становится рамкой и
встаёт в карусель после нарисованных. Требования: квадрат, центр
прозрачный, сама рамка по краю. Рабочий размер — 1024×1024.

## Админка

`/admin` для тех, чьи id перечислены в `ADMIN_IDS`:

* **Статистика** — люди, генерации, звёзды, доля платящих, средний чек и
  выручка на человека;
* **По дням** — таблица за 14 дней: новые, генерации, платные, звёзды;
* **Топы** — по тратам и по приведённым людям;
* **Платежи** — последние 15 с суммой и тем, за что платили;
* **Найти человека** — по id или `@username`: когда пришёл, сколько
  резал, сколько потратил, кого привёл;
* **Рассылка** — копией, с выбором «всем» или «активным за месяц»;
* **История рассылок** — сколько дошло, сколько заблокировали.
